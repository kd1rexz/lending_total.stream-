# T86 — быстрая шапка и слайдер кейсов

root, 19 октября 2026. Исходное локальное состояние T85.

Пути: src/components/sections/{SiteHeader,Cases,ContactVariants}.astro, src/scripts/case-carousel.ts, tests/e2e/{header-scroll,case-carousel,landing}.spec.ts, docs/{contracts,task-board}.md.

Шапка: прозрачная постоянно, движение300ms без opacity-анимации. Скрытие по направлению сохранено. Кейсы: одна обложка+название+краткое описание, листание кнопками/клавиатурой/нативнымtouch. Без JS горизонтальная лента сохраняется. Автопрокрутки нет. Старые подробности задача/решение/результат и метаданные удалены из UI; данные CaseStudy и существующая валидация не менялись, краткое описание берётся из task. Preview при пустом наборе —3 нейтральных технических слайда с временным изображением и явно незаполненными названиями, production не получает эти слайды. В контактах фиолетовые слова «в эфир» на существующем светлом фиолетовом текстовом токене; lime-иконки/ссылки сохранены.
