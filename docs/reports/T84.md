## Изменения

- Шапка сохраняет исходные логотип/название/ссылки и прозрачность на Hero. При скролле вниз скрывается плавно, при движении вверх появляется в любой части страницы на тёмной подложке. Порог направления10px защищает от мелких колебаний. Меню/focus-visible удерживают её видимой. Reduced motion отключает переход. Без JS навигация доступна исходным способом.
- Из Hero удалено только прежнее увеличение padding при открытии мобильной навигации, поскольку закреплённая шапка теперь накладывается и не должна сдвигать контент. Заголовок/фото/CTA/анимация подсказки не менялись.
- У Trust удалена только видимая подпись о демонстрационных логотипах. Сетка, изображения и preview-флаги сохранены.
- Три композиции «События в деталях» подряд только в preview: один ведущий кадр и описание, галерея, компактный список. Нет подписей «Вариант1/2/3». Использованы текущие иллюстрации форматов; нет вымышленных названий заказчиков, фактов и результатов. Незаполненность материалов обозначена. Реальный Cases для production сохранён.
- FAQ: заголовок над вопросами, без пустой левой колонки; max-width64rem, вопросы20px/18pxmobile, высота строк от72px. Старые тексты, native details, вращение плюса и плавное раскрытие сохранены.
- Контакты: фон #202124 как остальные серые секции, белый заголовок до44px, ссылки на основном шрифте без круглого характера акцентной телефонной надписи, ровные вертикальные строки с разделителями, лаймовые иконки. Телефон/tel, email/mailto и Telegram сохранены.
