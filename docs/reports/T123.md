# T123 — просмотр временного сайта без логина

4 ноября 2026 года по поручению владельца открыт доступ к клиентскому стенду. [Временный сайт](https://totalstream.201-51-31-242.sslip.io/).

Из файла `/opt/app/data/certbot/conf/total-stream-stage/site.conf` на Timeweb удалены две директивы HTTP Basic Auth. Предыдущая конфигурация сохранена в закрытом каталоге `/opt/total-stream-handoff/`. Выполнены `nginx -t` и мягкая перезагрузка конфигурации.

До изменения сайт отвечал 401 без учётных данных. После изменения новый сеанс Chromium с экраном 390 × 844 получил HTTP 200 по публичному имени и загрузил фото кейса. В ответе отсутствует `WWW-Authenticate` и присутствует `X-Robots-Tag: noindex, nofollow`. Соседний сайт вернул HTTP 200 по HTTPS до и после применения. Временным сайтом может пользоваться любой, у кого есть ссылка.
