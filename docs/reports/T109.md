# T109 — реквизиты ИП в подвале

1 ноября 2026 года. Владелец root. По выбору пользователя подвал показывает три поля из карточки исполнителя — имя ИП, ИНН и ОГРНИП. Имя занимает первую строку, на телефоне поля идут в одну колонку. Якорь просмотра — `/#requisites`.

Данные находятся в `src/data/site.json`. Изменены тип и схема данных, передача в SiteFooter на главной, сам подвал, документация и существующая проверка SEO. Номера сверены со скриншотом и проверены по контрольным цифрам. Локальная главная возвращает ровно три согласованных значения. Объём поставки — локальная версия и GitHub.

На macOS прошли типизация Astro, сборка preview и две браузерные проверки в Chromium и WebKit, включая ширину 360 px.
