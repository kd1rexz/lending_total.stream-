# T44 — Три варианта услуг подряд

T44, 16 октября 2026: по запросу пользователя в preview вместо одного блока услуг последовательно показаны три рабочих варианта «Форматы под вашу задачу»: сетка 2×2 с заголовками-триггерами примеров; нативный аккордеон с одним открытым форматом; переключатель с общей сценой и одной видимой кнопкой. Тексты одинаковые, короткие теги удалены из сравнительных блоков. Графика — декоративные SVG по форматам, не реальные фотографии/кейсы. #services ведёт к первому варианту; следующие имеют собственные id. Production сохраняет исходный Services до выбора. ServiceExamples получил необязательные instance и presentation, ids модальных окон уникальны в каждом блоке. Переключатель поддерживает мышь, Enter/Space, стрелки, Home/End; без JS все панели доступны по якорям. Примеры в каждом варианте доступны без JS через details.
