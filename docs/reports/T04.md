## Поведение

SiteHeader получает навигацию только через props. Без JavaScript ссылки остаются видимыми в потоке страницы. После инициализации на ширинах меньше 1024 px появляется кнопка меню; она сообщает aria-expanded/aria-controls. Раскрытая навигация увеличивает высоту header, не перекрывает Hero. Escape закрывает её и возвращает фокус на кнопку. Выбор якоря закрывает меню и переводит фокус на целевую секцию. Desktop-переход по breakpoint восстанавливает видимые ссылки.

Hero использует статический монохромный poster из props, оптимизацию Astro Image в WebP, sizes=100vw, widths 640/960/1440 и приоритетную загрузку. При отсутствии poster остаются тёмная поверхность, сетка, декор и весь текст. Выраженная типографика повторяет первый концепт PDF; для мобильного заголовка использован мягкий перенос «Видео­трансляции», без отрыва одной буквы. Звёзды, тонкая сетка и шахматный разделитель декоративны. Основной CTA ведёт к contacts, вторичный к cases, нижняя ссылка к services. Небольшое «Рабочий макет» выводится только при isPreview.

Contacts — фиолетовая секция с белым и лаймовым текстом. Предоставленные ссылки выводятся по props; подписи канала зависят от kind. При пустом массиве в preview показано только «Контакты будут добавлены», без фиктивной ссылки. SiteFooter содержит логотип, год сборки, переданные контакты и ссылку наверх. Форм, запросов к CRM и вымышленных данных нет.

## Ограничения и запросы на общие файлы

Оркестратор уже подключил компоненты к странице и стенду. Общий `--font-mono` на macOS/Chromium отображал кириллицу с нежелательной serif-подстановкой; предложено использовать ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace. Оркестратор подтвердил исправление токена. Агент shared CSS не менял.

Сценарий без poster предусмотрен кодом, но отдельно в браузере не проверен: доступные страницы сейчас передают изображение. Финальный шрифт Corsa, оригинал логотипа и утверждённый poster остаются внешними материалами G2. Реальные контакты намеренно отсутствуют; весь выпуск production блокирует отдельный валидатор.

Независимые axe/E2E, WebKit/Safari, 200% увеличение, проверка бюджета и финальная общая сборка остаются T08/T09. После передачи этого отчёта редактирование файлов T04 остановлено.
