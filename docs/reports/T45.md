# T45 — Выбранная сетка и прокрутка форматов

T45, 16 октября 2026: основной Services заменён выбранной сеткой 2×2 без подписи «Сетка 2×2». По всей карточке действует один нативный триггер примеров; hover меняет обводку и заголовок на светлый фиолетовый и увеличивает карточку на 1,2%. При reduced motion увеличение отключено, клавиатурный фокус выделяет обводку. Без JS закрытый summary также растянут по карточке; после раскрытия содержимое остаётся доступным.

По дополнению пользователя после сетки в preview возвращён вариант «названия слева, содержимое справа» — ServiceScroll. При прокрутке блок закрепляется на время четырёх форматов, выбранный пункт выделяется фиолетовым, прежняя панель затухает за 160 мс, новая появляется за 320 мс. Скролл обычный, колесо не перехватывается; после последнего формата блок освобождает страницу, обратная прокрутка возвращает предыдущие форматы. Нажатия и клавиатура тоже работают. На телефоне выбор расположен сеткой 2×2 над панелью. Закрепление включается только если любой из форматов полностью помещается по высоте; на низких экранах и при reduced motion остаётся компактный ручной переключатель. Без JS видны все панели. Старый аккордеон и компонент тройного сравнения удалены. Scroll-вариант пока только для preview; основная сетка применяется во всех режимах.
