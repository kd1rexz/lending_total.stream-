## Поведение

Четыре кнопки «Смотреть примеры» открывают нативные dialog с содержимым соответствующего формата. URL не меняется, новые маршруты не создаются. Предусмотрены обложка, название проекта, задача, выполненная работа, результат и необязательная ссылка на запись. Ссылка на запись открывает новую вкладку и не подключает сторонний плеер.

Закрытие работает через крестик, Escape и клик по затемнению. Перетаскивание из контента наружу не закрывает окно. Фокус возвращается кнопке, фон блокируется, длинное содержимое прокручивается внутри; панель закрытия остаётся видна. Без JavaScript те же данные раскрываются через details прямо под услугой. На телефоне раскрытый fallback занимает полную ширину строки.

`CaseStudy.serviceIds` связывает проект с одной или несколькими услугами; слой getPageContent передаёт компонентам готовые `examples`. Неизвестные/повторные связи отклоняются. В production учитываются только опубликованные кейсы и требуется хотя бы один пример для каждой опубликованной услуги. Preview допускает отсутствие материалов. Реальные кейсы сейчас отсутствуют, поэтому на основном сайте показывается «Примеры скоро появятся»; синтетические карточки существуют исключительно на отдельном тестовом стенде.
