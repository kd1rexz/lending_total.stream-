Проверки: Windows/Node24.15/Chromium. pnpm test:validation — 17/17, включая preview со staging URL, production URL карты и отсутствие вымышленных фактов в schema/безопасную сериализацию. pnpm build — успешно, 54 публичных файла; прежние предупреждения пустых cases и смешанного импорта изображений. pnpm check — 64 файла, 0 errors/warnings/hints. Живой dev /sitemap.xml и meta robots проверены при 390/1366, футер визуально просмотрен на скриншотах output/qa/T103.

Ограничения: production-сборка/публикация, реальные серверные заголовки, полные E2E/другие движки и повторный Lighthouse не проверялись. Готовность schema production проверена тестами генератора, но не рендером полного production с реальными материалами. Публичный выпуск по-прежнему требует данных компании и отдельного разрешения. Коммит/push не выполнялись.

Правовой ответ проверен по ГК437 и 152-ФЗ18.1. Сам факт сайта не требует оферты/политики; обязанность определяется заключением договора и реальной обработкой. Существенная оговорка: подготовленный Nginx пишет IP в access_log; фактический VPS не проверен. Это не аналитика, но требует оценки перед выводом об отсутствии персональных данных.
