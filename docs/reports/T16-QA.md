QA изменяет только этот отчёт и `output/qa/T16-independent/`. Код сайта, данные, зависимости и общие документы не изменялись.

## Найденные дефекты

- **P3, исправлен оркестратором и принят QA:** в no-JS details на 360 px длинные слова разрывались неудачно: «Многокамерны / е», «Демонстрацио / нный». Исходное состояние сохранено в `*-360-nojs-before-P3.png`. Оркестратор предоставил раскрытому содержимому полную ширину строки и уменьшил внутренние поля. Повтор `node output/qa/T16-independent/recheck-nojs.mjs` в 09:59 МСК: exit 0, Chromium и WebKit прошли. Полезная ширина заголовка — 286 px, переносы исправлены, нативное раскрытие и оба примера сохранены. Новые скриншоты просмотрены через view_image. Дополнительно сняты `*-360-nojs-viewport.png` и `*-360-nojs-last-viewport.png`; обычные кадры viewport предпочтительнее длинного element screenshot для оценки закреплённых элементов. Итоговые хеши изменённых компонентов — в `recheck-nojs.json`.
- Критических и существенных дефектов поведения в проверенном снимке не найдено.

Первый диагностический прогон пересёкся с HMR. До итогового прогона также исправлены ошибки самого QA-стенда: explicit browser context для axe, macOS Option+Tab, преобразование file URL в путь, ожидание lazy-image перед скриншотом. Их не учитывали как дефекты сайта и не использовали для заявления о прохождении. Промежуточный диагностический результат сохранён как `results-initial-harness.json`.

## Ограничения и общие файлы

- Использованы только изолированные тестовые кейсы. Подлинность, реальные фото и записи проектов ожидают T10.
