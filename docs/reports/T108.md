# T108 — телефон и Telegram

В `src/data/site.json` внесены два контакта владельца. Предпросмотр и основная сборка получают их из одного источника. В разделе контактов телефон отображается с пробелами, а при копировании сохраняется в международном формате. Кнопка рядом с Telegram копирует имя пользователя.

Изменены ContactVariants, данные сайта, README и существующие проверки контактов в contact-variants.spec.ts, interaction-options.spec.ts и landing.spec.ts.

На macOS прошли `pnpm check`, сборка preview и восемь браузерных проверок в Chromium и WebKit, включая отображение при ширине 390 и 1440 px, адреса ссылок и копирование обоих значений. Поставка охватывает локальную версию и GitHub.
