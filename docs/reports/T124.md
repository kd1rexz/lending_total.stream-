# T124 — диагностика HTTPS временного адреса

5 ноября 2026 года. По скриншоту Safari проверено временное имя `totalstream.201-51-31-242.sslip.io`.

`curl --interface en0` с Mac получил HTTP 200 на HEAD и GET с проверкой сертификата. Сертификат Let's Encrypt YE2 содержит нужное DNS-имя и действует до 2 февраля 2027 года. Через SSH на VPS выполнен `nginx -t`. HTTPS-запрос с сервера через локальный адрес с тем же SNI получил 200 и успешную проверку сертификата. Соседний сайт тоже получил 200. Доступная память на момент проверки 954 МиБ из 1895 МиБ.

Стандартный маршрут на Mac идёт через `utun21`, активен Happ. Через этот маршрут удалось воспроизвести таймаут после TLS ClientHello. Прямой маршрут через `en0` успешно завершает TLS и HTTP. Проверка альтернативных имён nip.io через текущий маршрут также остановилась на TLS. Поэтому добавление второго имени на сервере само по себе пока не подтверждено как решение. Сбой воспроизводится на сетевом маршруте Mac.

Повторное управление Safari инструмент остановил из-за ограничения текущего URL. Визуальная проверка Safari не завершена. Серверная конфигурация в рамках диагностики сохраняется. Отправлен запрос владельцу на исключение конкретного домена из VPN. До ответа изменение маршрутизации ожидает согласования.
