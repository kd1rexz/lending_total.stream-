# T21 — Плавное вращение звёзд при прокрутке

Автор: root. 15 октября 2026 года. Исходный коммит: `c13fc2a`.

## Изменения

`src/components/brand/Star.astro` подключает общий модуль `src/scripts/scroll-stars.ts` и отмечает декоративные звёзды атрибутом data-scroll-star. Astro включает модуль один раз для всех экземпляров. Угол связан с вертикальной прокруткой: 0.12 градуса на пиксель, один оборот на 3000 px. requestAnimationFrame сглаживает движение с постоянной времени 110 мс; обратная прокрутка меняет направление. После достижения целевого угла цикл останавливается.

Применено отдельное CSS-свойство rotate: исходные transform, включая наклоны декора секций, сохраняются. Логотип не участвует в анимации. При reduced motion вращение отключено и в CSS, и в JS; изменение системной настройки учитывается без перезагрузки. При скрытии вкладки запланированный кадр отменяется. Без JavaScript звёзды статичны.

Обновлены `docs/technical-spec.md`, `docs/contracts.md`, `docs/task-board.md`, добавлен `docs/reports/T21.md`. Props, данные и зависимости не менялись.
