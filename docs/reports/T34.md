# T34 — Исходный логотип, навигация и один CTA

Завершено 16 октября 2026 года, root.

## Реализованное поведение

T34, 16 октября 2026. По последним указаниям пользователя в Hero остаётся ровно одна компактная лаймовая кнопка «Обсудить проект», без стрелки, на месте прежней фразы «От подготовки площадки до записи эфира». В шапке CTA нет; кнопка «Смотреть кейсы» удалена. Навигация desktop увеличена с 14 до 16 px. Между знаком и wordmark в шапке 16 px (на самых узких экранах 8 px). Общий Logo использует исходный PNG logo-source.png 1672×941 напрямую, без resize/WebP/пересжатия; прозрачные поля скрываются CSS-рамкой, рисунок не обрезан. Исходник совпадает по SHA256 с приложением пользователя. Все звёзды основного сайта и слово «ключ» используют #3509AE. Для читаемости тёмного фиолетового слово «ключ» размещено на светлой подложке.
