# Total Stream

Статический лендинг на Astro, TypeScript и CSS. Работа ведётся в фиолетово-лаймовом концепте. Кейсы находятся на главной, связь — через контакты, без форм.

Готов локальный preview G1. Проверки и оставшиеся условия публикации — в [отчёте приёмки](docs/reports/T09.md). Контакты и кейсы добавляются после получения реальных материалов.

## Локальный запуск

Node.js 24.15.0, pnpm 11.25.0. Версии зафиксированы в проекте.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://localhost:4321. Стенд компонентов: `pnpm dev:components` на порту 4322.

```sh
pnpm check
pnpm build
pnpm preview
```

По умолчанию сборка preview с noindex. Production требует `BUILD_CONTEXT=production`, реальный HTTPS `SITE_URL`, контакты и утверждённые материалы. Команда build проверяет эти условия.

## Работа в VS Code

Открой папку проекта. Рекомендованные расширения перечислены в `.vscode/extensions.json`. В меню Terminal → Run Task доступен запуск сайта и проверка со сборкой. Для обычной работы достаточно `pnpm dev` в терминале.

## Где менять содержание

| Данные                         | Файл                                                |
| ------------------------------ | --------------------------------------------------- |
| Название, описание, контакты   | `src/data/site.json`                                |
| Навигация                      | `src/data/navigation.json`                          |
| Услуги                         | `src/content/services.json`                         |
| Кейсы                          | `src/content/cases.json`                            |
| Команда, FAQ, отзывы и клиенты | `src/data/editorial.json`                           |
| Источники и статус медиа       | `src/data/assets.json` и `docs/content-register.md` |
| Цвета и размеры                | `src/styles/tokens.css`                             |

Статус `published` у кейса или услуги устанавливается после проверки текста. Пустые отзывы и клиенты скрыты. Пока контакты и кейсы не предоставлены, основной preview показывает нейтральное пустое состояние. Заполненные карточки и тестовые контакты можно проверить в отдельном стенде компонентов; стенд не входит в dist.

В услугах «Смотреть примеры» открывает окно поверх страницы. Чтобы проект появился в нужном окне, добавь в его `serviceIds` идентификатор услуги из `services.json` (можно несколько). Отдельные страницы не создаются; без JavaScript примеры раскрываются прямо в секции. Перед production у каждой опубликованной услуги должен быть хотя бы один опубликованный пример.

## Проверки

```sh
pnpm check
pnpm test:validation
pnpm build
pnpm test:e2e
pnpm check:budgets
pnpm format:check
```

Перед первым запуском E2E: `pnpm exec playwright install chromium firefox webkit`. Тесты используют готовый dist и сами запускают preview на порту 4323. Отчёты сохраняются в `output/qa`. Проверка WebKit не заменяет финальную ручную проверку Safari на устройстве.

## Публикация

Сборка выполняется вне VPS. Nginx отдаёт статические файлы; постоянно работающий Node-сервер не требуется. Шаблоны и инструменты находятся в `infra/` и `scripts/deploy/`, команды описаны в [инструкции поставки](infra/README.md). До получения реального домена, контактов и материалов production намеренно заблокирован. Не снимай guard для публикации черновика.
